## Appeal: Guideline 4.1(c) — Copycats / Brand Misuse

We are appealing the rejection under Guideline 4.1(c). Our app name "OllamaChat" does not violate this guideline for the following reasons:

**1. "Ollama" is used descriptively, not as brand imitation**

"OllamaChat" uses "Ollama" in a descriptive manner to indicate compatibility — this app is a chat client for the Ollama platform. The app clearly identifies itself as an independent client, not the official Ollama product. Our privacy policy states: "OllamaChat is an independent client application. It is not affiliated with Ollama, Inc. or any AI model provider." All AI model names in the app include proper brand attribution (e.g., "Llama 3.2 (by Meta)", "Gemma 2 (by Google)").

**2. Precedent: Other apps using "Ollama" are already approved**

Multiple apps currently on the App Store use "Ollama" in their names and have been approved by App Review:

- "Reins: Chat for Ollama" (id6739738501) by Ibrahim Cetin — rated 4.6 stars, publicly available on the App Store. This app also uses "Ollama" descriptively to indicate it is a chat client for the Ollama platform.

If "Ollama" in an app name constituted a 4.1(c) violation, these apps would not have been approved. We respectfully ask that the same standard be applied consistently.

**3. Ollama is open-source software**

Ollama is an open-source project (github.com/ollama/ollama, MIT license). Using the name of an open-source project to indicate compatibility is standard practice in the software ecosystem. This is how users find tools that work with the platforms they use.
